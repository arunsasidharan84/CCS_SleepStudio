## CCS Sleep Studio 1.26.0

Faster, more predictable reviewing of long recordings.

### Fixes
- **Markers no longer disappear after filtering.** Applying a display filter (or changing other settings that rebuild the view) used to remove markers and events from the waveform and the hypnogram until the file was reopened. They now stay.
- **Filtering no longer freezes long recordings.** Applying a filter used to re-filter the whole night of the spectrogram channels on the main thread, which froze low-spec computers. Filters are now display filters only: applying one redraws the current window instantly.

### Improvements
- **Efficient display filtering.** Only the window on screen is filtered, with a few seconds of real signal on each side, using flat buffers and cached filter designs. The filtered window now matches filtering the whole night (the old window-only filtering showed a transient at the window edges).
- **Spectrogram off by default**, with a new **spectrogram [ON/OFF]** toolbar button. The full-night spectrogram and the SWA overlay are computed only when it is on; the setting is saved with the recording's configuration. The current epoch's spectrum is still shown.
- **Selection durations on the plot.** Each mouse-selected box shows its duration underneath; with several boxes, the last one also shows the cumulative duration (Σ). The total was removed from the status bar.
- **Right-click a channel** (name or trace) to hide it, show hidden channels again, or open its settings.
- **filter** toolbar button opens the Filters tab of the configuration.

### Notes
- Existing configurations open with the spectrogram off; press **spectrogram** once per recording to turn it back on.
