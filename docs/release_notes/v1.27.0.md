## CCS Sleep Studio 1.27.0

Interactive marker creation, smooth synchronized video scrubbing, flexible frequency bands, and automatic update prompts.

### Improvements
- **Prompt to update at startup:** The app now automatically checks for updates on launch. If a newer release is found, an update prompt is displayed with release notes and one-click update actions. Offline starts fail silently without interrupting the workflow.
- **Smooth video slider scrubbing:** Dragging the video slider no longer stutters or lags. High-precision libmpv seeks are throttled during active scrubbing, and waveform epoch paging is coalesced at 60 FPS. Frame-accurate seek executes instantly on release.
- **Click-to-add markers:** Added provision to place point markers or interval markers directly at the mouse click without having to draw a selection window first:
  - Right-click anywhere on the waveform trace to add a marker at that exact second, quickly mark common events (Artifact, Arousal), or delete existing overlapping markers.
  - Double-click on the waveform to open the Add Marker dialog prefilled with timestamp and channel.
- **Spectrogram hidden when off:** When the full-night spectrogram is toggled off, the panel and splitter are hidden, automatically redistributing 100% of the top strip width to the hypnogram and power spectrum.
- **Video time format matches viewer mode:** The video slider and waveform video cursor now respect the active time mode (`eegPanelTimeUnit`). In elapsed time mode, both display elapsed time (`HH:MM:SS`) instead of defaulting unconditionally to clock time.
- **Flexible frequency band configuration:** Frequency band limits for spectral feature extraction (PSD, IRASA, FOOOF) can now be freely defined, added, or edited in the Configuration dialog and Batch tab, including a dedicated Theta-Alpha (4–12 Hz) band option.
- **Windows update SSL certificate fix:** Added custom certificate verification for GitHub API and release download hosts to prevent `CERTIFICATE_VERIFY_FAILED` errors on Windows.
