## CCS Sleep Studio 1.27.1

High-performance streaming EDF conversion, seamless non-EDF file analysis, easy marker & selection removal, and time unit synchronization.

### Improvements & Fixes
- **Video cursor and slider time unit matching:** The video cursor badge and video slider elapsed format strictly respect the active time units (`Seconds` as `${sec}s`, `Minutes` as `${min} min`, `Hours` as `${h}h`, and `Clock time`).
- **Easy marker removal & selection box dismissal:**
  - Right-clicking on or near any marker displays a prominent "Delete marker" option with generous hit tolerance (1.5 seconds) at the top of the context menu.
  - Clicking empty waveform space immediately deselects and removes active selection boxes.
  - Added `Escape` key shortcut to dismiss any active selection boxes.
  - Added per-marker delete buttons and a "Clear All Markers" option with confirmation inside the Markers & Annotations dialog (`M`).
- **Fixed AnalyseNidra detection error and app crash on .EEG files:**
  - Wrapped AnalyseNidra detection with automatic native EDF conversion (`_nativeEdfFor`) so Nihon Kohden `.EEG` files run detection seamlessly without parsing errors.
  - Fixed duplicate `Navigator.pop()` in error handling that caused black/blank screens and subsequent app crashes.
- **High-performance streaming EDF conversion:**
  - Replaced dynamic Dart `List<int>` memory allocation loops with zero-allocation `ByteData` streaming via `RandomAccessFile`, cutting .EEG conversion time from 60 seconds to ~1 second with minimal memory usage.
  - Automatically reuses loaded in-memory recordings and downsamples high-frequency recordings (>200 Hz) to 200 Hz for rapid analysis.
- **Utilities review & enhancements:**
  - Enabled non-EDF file support across all Utilities options, including AnalyseNidra Advanced Analysis, respiratory OSA, PLMS, and CAP analyses.
