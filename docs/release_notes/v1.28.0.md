## CCS Sleep Studio 1.28.0

Comprehensive batch analysis enhancements, CAP integration, case-insensitive channel matching, direct preprocessed file loading, and official Windows app logo support.

### New Features & Improvements
- **CAP Analysis in Batch Processing & Master Sheet Integration:**
  - Integrated Cyclic Alternating Pattern (CAP) analysis into both the Batch EEG Pipeline and Batch PSG Polygraphy dialog.
  - Ensured all CAP metrics output with the standard `CAP_` prefix across CSV exports (e.g., `CAP_rate`, `CAP_A_index`, `CAP_A1_index`, etc.).
  - Automatically merges companion `_cap.json` metrics directly into the compiled `AnalyseNidra_master_sheet.csv`.
- **Sleep Cycle Prefix ("Cyc"):**
  - Updated sleep cycle metrics across ACCS, NeuroLoopGain (NLG), and Regional CSV exports to use the clearer `Cyc` prefix (e.g., `Cyc1_start_epoch`, `Cyc1_Sleep_duration_cycle`, `NLG_SW_Cyc1_NREM`) while retaining backwards-compatible aliases.
- **Autoload Scorings from External Folders:**
  - Added an external "Scoring folder" picker and input option in the Batch Recordings panel.
  - Automatically searches both the custom scoring folder and recording folder for matching scoring files (`.json`, `.csv`) by stem and base stem.
- **Case-Insensitive Channel Matching:**
  - Enabled case-insensitive and prefix/suffix-tolerant channel matching (`c3`, `C3`, `c3-m2`, `EEG C3-REF`, etc.) across native EDF readers, BrainVision VHDR loader, and frontend analysis tools.
- **Direct Preprocessed File Loading in Batch Analysis:**
  - Added support for loading preprocessed recordings (`*_clean.edf`, `*_stimclean.edf`, etc.) directly into batch analysis without discarding them or restarting raw file preprocessing.
  - Added "Prefer preprocessed files" option in the batch recordings list.
  - Automatic base-stem fallback ensures preprocessed files resolve parent scoring files seamlessly.
- **Official Windows App Logo & Title Bar Display:**
  - Replaced default Flutter placeholder icon with the official multi-resolution `app_icon.ico` (256x256 down to 16x16) for Windows builds.
  - Added explicit Win32 `WM_SETICON` calls (`ICON_BIG` and `ICON_SMALL`) so the taskbar and window title bar display the logo reliably.
  - Added app logo icon beside the application title in the top bar.
- **Multi-Instance Window Support & Datestamped Batch Exports:**
  - Added "New Window (Open another file)" command (`Cmd+N` / `Ctrl+N`) to run independent instances concurrently.
  - Batch export files now include timestamps (`AnalyseNidra_master_sheet_<timestamp>.csv` and `Batch_Scoring_Comparison_Master_<timestamp>.csv`) to prevent accidental overwrites.
  - Added "Clear File List" buttons with live counters to reload batch lists easily.
