## CCS Sleep Studio 1.29.0

New Group-level statistical analysis tab, Linear Mixed Models & GLM, publication-grade figures with significance markers, journal tables, publishing-ready DOCX & PDF reports, Windows updater SSL certificate fixes, and multi-user Linux server installer permission fixes.

### New Features & Improvements
- **Group-Level Statistical Analysis & Publishing Workbench (Tab 5 in Batch Analysis):**
  - Added dedicated "5  Group statistics" tab in Batch Analysis allowing researchers to evaluate cohort-level sleep differences.
  - Interactive data selection: Load any batch analysis results master sheet CSV (`AnalyseNidra_master_sheet.csv`) or previous runs with 1 click, plus optional external demographic/group metadata tables.
  - Interactive factor configuration: Interactively specify primary grouping factors (e.g., `Group`, `groupID`), secondary/within-subject factors (e.g., `Chan`, `ageID`), random-effects subject clusters (`Subject Identifier`, `napID`), and demographic covariates (`Age`, `Gender`, `Education`).
- **State-of-the-Art Statistical Modeling (LMM & GLM):**
  - **Linear Mixed-Effects Models (LMM):** Implemented using Restricted Maximum Likelihood (REML) estimation with subject-level random intercepts for multi-channel / repeated-measures neurophysiology metrics:
    `Outcome ~ Group * Channel + Covariates + (1 | Subject)`
  - **General Linear Models (GLM / ANOVA Type II):** Automatically selected for between-subject single-observation parameters (TRT, TST, WASO, SOL, Sleep Efficiency, stage percentages).
  - **Post-Hoc Pairwise Contrasts:** Automated pairwise t-tests with Benjamini-Hochberg False Discovery Rate (FDR), Tukey HSD, or Bonferroni adjustments, standardized effect sizes (Cohen's d and partial η²).
- **Interactive Visualizations & Publication Plots:**
  - In-app interactive plot viewer with boxplots, individual jittered data distributions, and post-hoc significance brackets labeled with standard scientific markers (`*`, `**`, `***`, `****`, `ns`).
  - High-resolution publication-quality PNG images (300 DPI) automatically exported into a datastamped `plots/` subfolder.
- **Journal-Friendly CSV Tables:**
  - Automated compilation of APA-formatted tables: `descriptive_statistics_<timestamp>.csv` (N, Mean ± SD, Median, IQR, Min, Max), `model_effects_<timestamp>.csv` (Coefficients, SE, statistics, df, p-values, 95% CIs), and `posthoc_comparisons_<timestamp>.csv` (Pairwise contrasts, mean differences, adjusted p-values, effect sizes).
- **Publishing-Ready Scientific Reports (DOCX & PDF):**
  - User can choose to export reports in Microsoft Word (`.docx`), Portable Document Format (`.pdf`), or both simultaneously.
  - Full scientific manuscript structure: Title, Executive Summary, Demographic Sample Breakdown, Statistical Methodology, Metric-by-Metric Statistical Narratives, APA Tables, and High-Resolution Embedded Figures with captions.
- **Windows In-App Updater SSL Fix:**
  - Fixed `CERTIFICATE_VERIFY_FAILED: unable to get local issuer certificate` during in-app updates on Windows by properly configuring the TLS trust callback for AWS S3 and GitHub CDN release binary redirects.
- **Linux Multi-User Server Temp Permission Fix:**
  - Resolved `PathAccessException: Cannot delete file (Operation not permitted, errno = 1)` on shared Linux servers by allocating user-isolated temporary directories for downloaded updates and installation scripts.
- **Windows Title Bar Display:**
  - Fixed Windows window title displaying `sleep_eeg_desktop` by updating native Win32 window creation to `CCS Sleep Studio`.
