## CCS Sleep Studio 1.37.5

Unified PSG batch analysis pipeline with flexible substep toggles, restructured Utilities menu with logical categories, complete zero-Python migration with pure Dart statistical engine, multi-row post-hoc scalp topoplots, robust outlier scaling, and cross-platform reliability improvements on Windows and Linux.

### Key Highlights & Improvements

#### 1. Unified PSG Batch Analysis Pipeline with Substep Toggles
- **Unified Pipeline Architecture:** Merged previously disjoint "EEG Analysis" and "Polygraphy: OSA & PLM" sub-tabs into a single cohesive **PSG Analysis** pipeline.
- **Flexible Substep Toggles:** All stages are now toggleable substeps that can be combined in multiple ways using interactive chips or in-card switches:
  `[✓ Autoscore] -> [✓ Preprocess] -> [✓ EEG Features] -> [✓ Respiratory / OSA] -> [✓ Limb / PLM] -> [✓ Compile Master Sheet]`
- **Run Any Combination:** Run any subset of stages (e.g., only Autoscore + Respiratory, Preprocess + EEG Features, or all 6 steps in sequence across all recordings).
- **Collapsible Step Cards:** Each step features its own settings card, status subtitle, in-pipeline toggle switch, and a dedicated **"Run this step only"** action.
- **Comprehensive Master Sheet Integration:** Companion polygraphy metrics from `_respiratory.json` (AHI, OAI, CAI, MAI, HI, RDI, ODI3, ODI4, SpO2 min, hypoxic burden, severity) and `_plm.json` (PLMS index, LM index, periodicity index, PLMS severity) are automatically detected and compiled directly into `AnalyseNidra_master_sheet_<timestamp>.csv` alongside spectral and micro-event metrics.
- **Standalone PSG Summary Table:** Produces `psg_batch_summary_<timestamp>.csv` whenever polygraphy reports are present, even when running standalone without EEG feature extraction.

#### 2. Restructured Utilities Menu
- Reorganized the flat 15-item Utilities menu into 6 intuitive, logical categories across both macOS native menus (`PlatformMenu`) and in-app menu bars (`MenuBar`/`SubmenuButton`):
  1. **SIGNAL PREPROCESSING & CLEANING:** Preprocessing Pipeline (Filters, RANSAC, GEDAI), Auto Electric Stim Artefact Removal (DBS), EEG Utilities Module (Crop, Downsample, Rename, Anonymize & Batch).
  2. **MICRO-EVENTS & TRANSIENT DETECTION:** Spindle Detection (MT-Spindle) `[Ctrl+Shift+S]`, K-Complex Detection (MT-KCD) `[Ctrl+K]`, AnalyseNidra Detection (Spindles & Slow-Waves), Cyclic Alternating Pattern (CAP) Analysis.
  3. **POLYGRAPHY: RESPIRATORY (OSA) & PLM:** Respiratory / OSA Analysis (AASM), Periodic Limb Movement (PLMS) Analysis, Show / Remove OSA, PLM & CAP Markers.
  4. **ADVANCED SLEEP EEG PIPELINE:** AnalyseNidra — Advanced Sleep EEG Analysis, Feature Selection & Extraction Parameters.
  5. **INTERACTIVE VIEWER TOOLS:** Zoom on Selected EEG `[Z]`, Find Similar Epochs from Current Epoch.
  6. **REPORTING & EXPORT:** Export Sleep Report (PDF).
- Enhanced visual hierarchy with category section headers, dividers, and leading icons.

#### 3. Complete Zero-Python Migration (Pure Dart Statistical Engine)
- **Eliminated Python Dependencies:** Removed all external Python runtime requirements (`statsmodels`, `scipy`, `numpy`, `matplotlib`, `seaborn`) for Group Analysis.
- **Pure Dart High-Performance Analytics:**
  - Linear Mixed-Effects Models (LMM) with subject-level random intercepts for repeated measures and multi-channel metrics.
  - General Linear Models (GLM) / ANOVA Type II for macroarchitecture parameters.
  - Multiple comparison corrections: Benjamini-Hochberg FDR, Bonferroni, Holm-Bonferroni, and Tukey HSD.
  - Standardized effect sizes: Cohen's d and partial $\eta^2$.
  - Descriptive statistics: Sample size ($N$), Mean $\pm$ SD, Median, IQR, Min, Max.
- **Native CustomPainter Visualizations:** Pure Dart rendering for publication-quality boxplots with individual jittered data points, robust outlier scaling (winsorization), unclipped titles, explicit units, sample counts, and legends placed outside the plot canvas.

#### 4. Multi-Row Post-Hoc Scalp Topoplots
- Scalp topographic maps (topoplots) now render multi-row pairwise difference contrasts for all cohort pairs (e.g., `OLD − MID`, `YNG − MID`, `YNG − OLD`).
- Empirical significance markers (`*` for $p < 0.05$) indicate statistically significant spatial clusters.
- High-resolution rendering prevents distortion and preserves aspect ratios.

#### 5. Cross-Platform Reliability & Linux CI Fix
- Fixed Windows and Linux file path resolution issues in statistical batch scripts.
- Removed redundant Group Analysis top toolbar button.
- Added interactive factor filtering to inspect specific sub-cohorts and filter out outlier rows.
- Bundled offline RPM Fusion release packages and added direct origin fallbacks (`download1.rpmfusion.org`) for resilient AlmaLinux 8 / 9 CI container builds.
