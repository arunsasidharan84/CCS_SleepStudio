## CCS Sleep Studio 1.37.7

Resilient PSG batch pipeline with 10-20 to 10-10 channel alias matching, lenient channel loading, independent step execution, and guaranteed sleep macro-architecture metrics in the compiled Master Sheet.

### Key Highlights & Improvements

#### 1. 10-20 to 10-10 Channel Alias Matching
- **Automatic Electrode Aliasing:** Added bidirectional matching in `find_header_index` for standard international 10-20 $\leftrightarrow$ 10-10 electrode nomenclature across EDF and BrainVision (`.vhdr`) loaders:
  - `T3` $\longleftrightarrow$ `T7`
  - `T4` $\longleftrightarrow$ `T8`
  - `T5` $\longleftrightarrow$ `P7`
  - `T6` $\longleftrightarrow$ `P8`
  - `A1` $\longleftrightarrow$ `M1`
  - `A2` $\longleftrightarrow$ `M2`
- **Broad Montage Compatibility:** Recordings labeled using legacy 10-20 labels seamlessly resolve against modern 10-10 channel configurations without manual renaming.

#### 2. Lenient Channel Loading (`read_available`)
- **Fault-Tolerant Preprocessing & Features:** Switched Preprocessing (`run_preprocessing`) and Feature Extraction (`load_recording`) from strict channel verification (`read_selected`) to lenient channel loading (`read_available`).
- **Graceful Partial Montages:** Clinical recordings missing individual electrodes (e.g., `T7` absent in a 21-channel montage) no longer crash or fail the entire recording. The pipeline logs a clear warning notice and continues processing all available channels.

#### 3. Decoupled Pipeline Dependencies in PSG Batch Run
- **Independent Substep Execution:** Removed indiscriminate blocking where a failure in Preprocessing previously blocked all subsequent stages for that recording.
- **Robust Fallback:** If Preprocessing fails or is skipped, all downstream steps (**Features**, **CAP**, **Respiratory / OSA**, and **PLM**) proceed normally. Feature extraction automatically falls back to the raw source recording when a preprocessed file is absent.

#### 4. Guaranteed Sleep Macro-Architecture in Master Sheet
- **Universal Architecture Metrics:** In the Master Sheet compilation stage, if a recording has a valid hypnogram (from Autoscore or manual staging) but lacks a regional feature CSV, `analyse-nidra` automatically computes macro-architecture metrics via `--analyses none`.
- **Complete Cohort Inclusion:** All 38 sleep macro-architecture metrics (Total Sleep Time [TST], Sleep Efficiency [SE], Wake After Sleep Onset [WASO], Sleep Onset Latency [SOL], Stage Durations & Percentages [N1, N2, N3, REM, WAKE], Transition Counts, and Stage Bout Dynamics) are guaranteed to be compiled into `AnalyseNidra_master_sheet_<timestamp>.csv` for every scored recording.
