## CCS Sleep Studio 1.39.1

Robust multi-rate EDF handling for spindle & slow-wave detection, comprehensive marker visibility manager in the top-level Events menu, clinical AASM montage ordering with pre-referenced channel waveform preservation, and cross-platform Windows runner path fixes.

### Key Highlights & Improvements

#### 1. Cross-Platform Windows CI Reliability
- **Normalized Path Separators:** Standardized path separator resolution across Windows and Unix platforms in `LegacyFileMigration` and recording storage tests, ensuring flawless compilation and test execution on Windows runner environments.

#### 2. Native AnalyseNidra Multi-Rate EDF Spindle & Slow-Wave Detection
- **Modal Sampling Rate Clustering:** In `analyse-nidra`, EDF channel loading (`read_available`) now dynamically clusters channels by modal sampling rate. Matching EEG channels are loaded successfully, while auxiliary channels with divergent sampling rates (e.g. 500 Hz Snore or 1 Hz SpO2 in files like `S4.edf`) are gracefully skipped with informative diagnostic logging instead of failing the run.
- **Root-Based Channel Key Matching:** Upgraded channel resolution in `load_with_epoch` to utilize `read_eeg_channels` and normalized root matching (e.g. `F3` matches `EEG F3-A2`), preserving loaded traces when no re-referencing is requested.
- **Defensive Safeguards:** Eliminated unchecked index access panics by ensuring non-empty channel lists before running spindle and slow-wave detectors.
- **Targeted Channel Pickers:** Spindle and slow-wave detection dialogs now filter selectable channels strictly to EEG and mastoid electrodes, auto-defaulting references to `'None'` for pre-referenced derivations.

#### 3. Top-Level Events Menu & Comprehensive Marker Management
- **Promoted Menu Placement:** "Show / Remove Markers & Polygraphy Events" is now accessible directly under the top-level **Events** menu on macOS (`Events -> Show / Remove Markers & Polygraphy Events…`) as well as the in-app Events menu.
- **Extended Event Support:** Added full visibility management for **Sleep Spindles**, **Slow Waves**, and **K-complexes** in addition to Apneas, Hypopneas, Desaturations, EEG Arousals, PLMs, and CAP phases.
- **Live Event Counts:** The manager dialog displays real-time event counts for every marker category present in the active recording (e.g., `Sleep Spindles (142)`, `Slow Waves (86)`).
- **Fast Select/Deselect:** Added "Select All" and "Deselect All" quick-action chips for rapid toggling.
- **Instant Hot-Reload:** Restoring previously hidden markers automatically triggers event reload hooks, immediately displaying detected events without needing to reload the recording.

#### 4. Clinical AASM Montage Standardization & Waveform Preservation
- **Standard Clinical Layout:** Reordered the `AASM Sleep Standard` montage preset so EOG channels (`E1-M2`, `E2-M1` / `E2-M2`) are placed at rows 1 & 2 at the top of the display, preceding frontal, central, and occipital EEG derivations.
- **Pre-Referenced Channel Detection:** Added `findPreReferencedChannel` to identify channels recorded with hardware or acquisition pre-referencing (such as `E1:M2`, `E2:M2`, `EEG F3-A2`, `LOC-A2`). When detected, the montage binds directly to the recorded channel with `reReference: 'None'`, preventing artificial subtraction and eliminating sleep spindle leakage into EOG traces.
- **Modality-Specific Trace Coloring:** Enforced consistent trace colors: EOG channels are displayed in **Blue**, EMG in **Orange**, and ECG in **Magenta**.
