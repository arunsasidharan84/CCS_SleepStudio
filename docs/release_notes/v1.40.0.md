## CCS Sleep Studio 1.40.0

Guided clinical workflow bar, unified 1-click comprehensive analysis pipeline, research-grade Rapid Eye Movement (REM) detection, intuitive AnalyseNidra progress tracking, clinical AASM montage ordering with midline fallbacks, legacy file migration prompt and folder tool, and NeuroLoopGain clinical calibration.

### Key Highlights & Improvements

#### 1. Guided Clinical Workflow Bar
- **Top-Level Clinical Sequence:** Directly above the EEG viewport, an intuitive workflow bar guides clinicians through the standard sleep study process:
  $$\text{[1. Open File]} \longrightarrow \text{[2. AASM Montage]} \longrightarrow \text{[3. Autoscore]} \longrightarrow \text{[4. Review]} \longrightarrow \text{[5. Run Analyses]} \longrightarrow \text{[6. Generate Report]}$$
- **Live Status & Next Step Highlighting:** Displays completion checkmarks for finished steps, highlights the recommended next action, and opens the respective tool with a single click.

#### 2. Unified Comprehensive Analysis Pipeline (Step 5)
- **1-Click Multi-Modal Execution:** Added an All-in-One analysis dialog (`_runComprehensiveAnalysisDialog`) with batch toggles and individual run options for:
  - **AnalyseNidra Sleep EEG Pipeline** (Spectral powers, slow waves, spindles, and PAC)
  - **NeuroLoopGain (NLG)** Cortical closed-loop feedback stability
  - **Rapid Eye Movements (REM)** Conjugate ocular saccades and REM density
  - **Cyclic Alternating Pattern (CAP)** NREM sleep instability & A-phases
  - **Respiratory & Sleep Apnea (OSA)** Apneas, hypopneas, ODI, and AHI
  - **Periodic Limb Movements (PLMS)** Leg movements, periodic index (PLMI), and arousals
- **Automated Pipeline Runner:** Clinicians can select any combination of analyses and run the entire suite in one automated pass.

#### 3. Clinical Sleep Report Generator (Step 6)
- **Clinical Impressions & History:** Added an integrated dialog allowing physicians to input **Subject ID**, **Clinical Notes / History / Physician Impression**, **Study Site**, and **Reporting Physician**.
- **Publication PDF Export:** Generates publication-grade multi-page sleep study PDFs with macro-architecture, hypnograms, spectral power, morphometry, and respiratory/PLM/CAP summaries.

#### 4. Research-Level Rapid Eye Movement (REM) Detection
- **Conjugate Saccade Dynamics:** Introduced `RemDetector` analyzing bilateral EOG derivations (`LOC/E1` and `ROC/E2`) for out-of-phase deflections, calculating deflection velocity ($\mu\text{V/s}$), peak amplitude ($\mu\text{V}$), duration, and REM density ($\text{events}/\text{min REM}$).
- **Automated Annotation & `.ccsrem` Export:** Automatically marks saccades on the hypnogram and waveform and exports `<stem>.ccsrem` (with companion `<stem>_rem.json`).

#### 5. Intuitive AnalyseNidra Progress Tracking
- **Step Tracker Pills:** Replaced the overwhelming raw terminal dump with a clean visual progress indicator tracking pipeline stages (`Channels` $\to$ `Core Spectral` $\to$ `PAC` $\to$ `Slow Waves` $\to$ `Spindles` $\to$ `NeuroLoopGain` $\to$ `Regional Output`).
- **Active Status Card:** Displays the current operation, percentage progress bar, and active recording.
- **Collapsible Terminal Console:** Added `[Show / Hide Terminal Log Console]` toggle button so clinicians can inspect low-level logs when desired without visual clutter.

#### 6. AASM Montage Ordering, Derivation Deduplication & Midline Fallbacks
- **Standard Clinical Layout:** Enforces strict clinical sequencing: **EOG (Rows 1–2) $\to$ Frontal $\to$ Central $\to$ Occipital $\to$ Chin EMG**.
- **Prefix & Suffix Normalization:** Automatically strips prefixes (`EEG `, `POL `) and suffixes (`-Ref`, `_Ref`) during channel combination to prevent duplicate labels like `EEG F4-Ref-EEG M1-Ref`.
- **Raw Channel Screen Deduplication:** When montage derivations are active, unconfigured raw channels are set to `displayOnScreen = false`, eliminating duplicated or cluttered raw waveforms on screen.
- **Extended Presets:** Added presets for `AASM Sleep + OSA (Respiratory)` and `AASM Sleep + PLM (Limb Movements)`.
- **Midline Electrode Fallbacks:** Automatically falls back to midline electrodes ($C_z$ when $C_3/C_4$ are missing, $F_z$ for $F_3/F_4$, $O_z$ for $O_1/O_2$) across both Rust and Dart backends.
- **Per-Channel Scales & Filters:** Added per-channel vertical scale selectors ($20\,\mu\text{V}$ to $1000\,\mu\text{V}$) and filter configuration dialogs.

#### 7. Legacy Sidecar Migration Tool & Startup Prompt
- **Startup Auto-Detection:** Automatically scans recording directories upon opening recordings and prompts users to migrate legacy `.json` sidecars (`.config.json`, `_scoring.json`, `_spindles.json`, etc.) to modern `.ccs*` extensions.
- **Batch Folder Migration Tool:** Added **Data / File ➔ Migrate Legacy Sidecars in Folder…** to scan and migrate any selected directory on disk with a preview list.
- **Config Picker Compatibility:** Allowed both `.ccsconfig` and `.json` in all configuration open/save dialogues.

#### 8. Marker Visibility & Group Management
- **One-Click Marker Management:** Integrated the `[Show / Remove Groups…]` button directly inside the **Markers & Annotations Manager [M]** dialog and main toolbar.
- **REM Group Visibility:** Added full support for Rapid Eye Movement (REM) markers in the visibility manager.

#### 9. NeuroLoopGain Referencing & Algorithm Calibration
- **Suffix Parsing Fix:** Fixed derivation splitting in `nlg.rs` where raw channels ending in `-Ref` were falsely flagged as pre-referenced, leaving them unreferenced and causing low gain output.
- **Mastoid Fallback:** Automatically falls back to mastoids (`M1/M2` / `A1/A2`) when unreferenced, restoring expected clinical loop gain values (35%–53%).
- **CLI Upgrades:** Added `--channels` flag support in the native CLI.
