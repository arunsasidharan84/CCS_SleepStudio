## CCS Sleep Studio 1.50.0

In-app rich Markdown and Unicode math release notes viewer, and a comprehensive 8-chapter Visual User Guide and Tutorial Wiki designed for clinicians, researchers, and non-technical sleep professionals.

### Key Highlights & Clinical Improvements

#### 1. In-App Rich Markdown & Scientific Math Release Notes Viewer
- **Native Markdown Parsing:** Replaced raw monospace markdown text in the "New Update Available!" dialog with `ReleaseNotesMarkdownView`.
- **Hierarchical Headings & Bullet Lists:** Accurately formats `#`, `##`, `###`, `####` headers, multi-level indented bullet points, and numbered lists.
- **Rich Inline Styling:** Clean rendering for **bold text**, *italic text*, and highlighted `code` badges.
- **Automatic Scientific Formula Cleanup:** Automatically translates LaTeX / KaTeX math notation (`\ge`, `\le`, `\mu`, `\pm`, `\times`, `\approx`, `\rightarrow`, `\Delta`, `\text{...}`) into crisp, human-readable Unicode scientific symbols ($≥$, $≤$, $μ$, $±$, $×$, $≈$, $→$, $Δ$, $\text{ms}$, $\text{bpm}$, $\mu\text{V}$).
- **Expanded Dialog Dimensions:** Widened update dialog from 580px to 640px and expanded release notes viewport height from 160px to 240px with a persistent scrollbar thumb.

#### 2. Comprehensive Visual User Guide & Tutorial Wiki
- **Designed for Non-Technical Users:** Step-by-step illustrated guide covering every stage of the clinical sleep workflow from installation to final publication report.
- **8 Dedicated Visual Chapters:**
  1. **Home / Table of Contents:** Overview, complete documentation index, master workflow flowchart, and essential keyboard shortcuts cheatsheet.
  2. **Getting Started & Installation:** Step-by-step guidance for macOS (Gatekeeper bypass), Windows desktop installer, Linux setup, and initial window orientation diagram.
  3. **The 6-Step Clinical Workflow:** Complete tour of the top workflow bar (EDF Load $\to$ Montage Mapping $\to$ AI Autoscoring $\to$ Manual Review $\to$ Advanced Analytics $\to$ Export & Reports).
  4. **Waveform Viewer & Inspection Tools:** Epoch time grid overlay (<kbd>G</kbd>), zoomed signal measurement caliper ($\Delta t$, instantaneous frequency $f = 1/\Delta t$, $\Delta V$, range), single-point click vs region markers, channel solo isolation, display font scaling, SpO₂ desaturation markers, and clinical decision aid tooltips.
  5. **Manual Sleep Scoring & Annotations:** AASM staging criteria (Wake, N1, N2, N3, REM), discrete event tagging (Apneas, Hypopneas, Limb Movements, Arousals), typable custom markers (<kbd>T</kbd>, <kbd>Shift</kbd>+<kbd>M</kbd>), and Annotations Manager.
  6. **Automated Cardiac & Arrhythmia Analysis:** AASM Section VIII Cardiac rules, Pan-Tompkins QRS energy detector, automatic detection for Asystole, Sinus Bradycardia, Sinus Tachycardia, PVCs, PACs, Couplets, Bigeminy/Trigeminy, VT/NSVT, SVT, and AFib.
  7. **Advanced Analysis & Publication Reports:** Spindle and Slow Wave co-occurrence, Phase-Amplitude Coupling (PAC), Non-Linear Gating (NLG), OSA/PLM polygraphy, and 5-page publication-quality PDF with 2D scalp topoplots and relative spectral trajectories.
  8. **Troubleshooting & FAQ:** Display amplitude calibration, non-destructive error recovery, EOG mastoid reference standardization, and 100% offline HIPAA/GDPR data privacy.
- **Dual Availability:** Formatted and available directly within the GitHub repository (`docs/wiki/`) and configured for GitHub Wiki integration (`wiki/`).
