## CCS Sleep Studio 1.50.1

Restored multi-channel selection for CAP analysis, and added comprehensive 10-20 to 10-10 electrode nomenclature harmonization across the channel picker dialog, the batch extraction engine, and master sheet compilation.

### Key Highlights & Clinical Improvements

#### 1. Restored Multi-Channel Selection for CAP EEG Analysis
- **Multi-Channel Picker:** Resolved an issue where the batch CAP channel field defaulted to single-select mode. Restored multi-channel checkbox selection across both the PSG polygraphy card and the batch extraction card.
- **Priority Fallbacks:** Allows selecting all channels or a priority candidate list (e.g. `C4, C3, CZ`) so each file in a batch automatically falls back across the specified channels.

#### 2. Channel Nomenclature Harmonization (10-20 $\longleftrightarrow$ 10-10)
- **Interactive Channel Picker Aliases:**
  - Electrodes with classic 10-20 labels display their modern 10-10 equivalent badges directly on the selection chip (`EEG T3 [T7]`, `EEG T4 [T8]`, `EEG T5 [P7]`, `EEG T6 [P8]`).
  - Search/filter now cross-references aliases bidirectionally: typing `T7` finds `EEG T3`, typing `P7` finds `EEG T5`, typing `T8` finds `EEG T4`, and typing `P8` finds `EEG T6`.
  - Added a `[✔] Standardize to 10-10 names (T3→T7, T4→T8, T5→P7, T6→P8, clean prefix)` toggle, returning clean, prefix-free canonical names (`C3, C4, CZ, ..., T7, T8, P7, P8`).
- **Master Sheet Compiler Harmonization:**
  - `compileRegionalCsvFiles` now automatically standardizes the `Chan` column across all selected CSVs, mapping legacy `T3/T4/T5/T6` to `T7/T8/P7/P8` and stripping `EEG `/`POL ` prefixes.
  - Enables compiling master sheets that combine recordings acquired with old and new montage conventions without row divergence or missing data splits.
- **AnalyseNidra Engine Per-Channel Normalization:**
  - In per-channel extraction mode, channel keys are automatically canonicalized to uppercase 10-10 names (`T7, T8, P7, P8`, `C3, C4...`), eliminating hardware prefixes and honoring custom region maps when specified.
