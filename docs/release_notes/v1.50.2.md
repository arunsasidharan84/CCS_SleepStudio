## CCS Sleep Studio 1.50.2

Robust metadata matching and key column auto-discovery to prevent subject collapsing in batch processing, enhanced token-bounded filename alignment, and master sheet metadata harmonization.

### Key Highlights & Clinical Improvements

#### 1. Robust Metadata Key Column Selection (`guessKeyColumn`)
- **High-Cardinality Uniqueness Heuristics:** Automatically inspects the ratio of distinct values across metadata rows. Categorical and grouping columns with low cardinality (such as `groupID`, `ageID`, `Gender`, `Status`, or `Slept_well` which only hold 2–3 distinct categories across dozens or hundreds of subjects) are penalized and prevented from being selected as primary matching keys.
- **Distinct Row Match Scoring:** Scores candidate columns based on the number of *distinct metadata rows* matched across cohort recordings. This ensures true primary identifiers (e.g. `napID`, `Subject_Code`, `subject_id`) decisively win over categorical columns that would otherwise greedily collapse all recordings onto 1 or 2 subject entries.
- **Categorical & Serial Number Demotion:** Words associated with grouping, demographics, or sequential ordering (`group`, `cohort`, `gender`, `status`, `stage`, `Sl.No.`) are penalized so they never supersede genuine recording or subject identifiers.

#### 2. Delimiter-Bounded Token Matching (`matchRecording`)
- **Token-Bounded Specificity:** When aligning recording file names against metadata keys, keys bounded by standard file delimiters (`_`, `-`, `.`, spaces) receive a high-priority token score (e.g. `Nap-122` within `CNT_MID_EX_Nap-122_D_...`).
- **Elimination of Greedy Substring Collisions:** Prevents short categorical codes (like `CNT` or `MCI`) or sequential digits (`1`, `2`) from triggering arbitrary substring containment matches across recording file stems.
