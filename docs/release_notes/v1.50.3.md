## CCS Sleep Studio 1.50.3

Complete auditability and provenance tracking with embedded application version across all CSV exports, coupled with strict batch collation integrity and verified macro sleep architecture preservation.

### Key Highlights & Clinical Improvements

#### 1. Embedded App Version for Traceback Across All CSV Exports
- **Master Sheets:** Both channel-wise and regional compiled master sheets (`AnalyseNidra_channel_master_sheet_*.csv` and `AnalyseNidra_regional_master_sheet_*.csv`) now embed an `'App Version'` column right beside `'Recording Date'`. Every row explicitly stores the exact application version and build number used during analysis and collation.
- **PSG Batch Summaries:** Polygraphy batch summary exports (`psg_batch_summary_*.csv`) log `'App_Version'` for complete traceability of respiratory, PLM, and CAP analysis runs.
- **Batch Scoring Comparison Sheets:** Master comparison tables (`Batch_Scoring_Comparison_Master_*.csv`) and multi-scorer agreement exports (`scoring_comparison.csv`) carry the active application version to traceback consensus scoring algorithms.
- **Group Statistics Reports:** Group ANOVA and post-hoc tables (`GroupStats_Summary.csv`, `GroupStats_PostHoc.csv`, `GroupStats_Descriptives.csv`) now include `'App_Version'` to provide reproducibility tracking for publication.
- **Individual CSV Preservation:** Individual regional and channel CSVs automatically receive the version attribute during collation and companion metrics synchronization without altering existing column schemas.

#### 2. Batch Macro-Architecture & Feature Collation Integrity
- **Demographic vs. Architecture Isolation:** Enforced strict separation between demographic metadata enrichment (`Age`, `Gender`, `Status`, `Education`) and PSG sleep architecture columns (`TRT`, `TST`, `WASO`, `SOL`, `Sleep_efficiency`, `W_duration`, `N1_duration`, `N2_duration`, `N3_duration`, `R_duration`).
- **Verified Cohort Parity:** Validated 100% recording length parity ($\text{TRT}$) across cohort runs with zero missing-channel data drops.
